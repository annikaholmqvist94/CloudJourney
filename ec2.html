Amazon EC2

Kategori: Beräkning

Amazon Elastic Compute Cloud (EC2) ger skalbar beräkningskraft i molnet i form av virtuella servrar, kallade instanser. Du väljer operativsystem, CPU/minne-storlek (instanstyp) och kan starta, stoppa eller skala antalet instanser efter behov istället för att äga fysisk hårdvara.

EC2 är grunden för många andra AWS-tjänster och passar för allt från webbservrar och API:er till batch-bearbetning och utvecklingsmiljöer. Auto Scaling kan lägga till eller ta bort instanser automatiskt utifrån belastning.

Bra att veta

  • Betalning sker per sekund/timme instansen körs.
  • Instanstyper är optimerade för olika behov (allmän, minne, GPU m.fl).
  • Kan kombineras med Elastic Load Balancing för att fördela trafik.
