# CloudJourney

En personlig katalog över AWS-tjänster, byggd med HTML5, CSS och vanilla
JavaScript. Varje tjänst har en egen sida med beskrivning och ett
självskattningsformulär där du loggar din förståelse och dina
anteckningar allt eftersom du lär dig tjänsten.

## Struktur

- `index.html` — startsida med tjänstlista, byggd dynamiskt från `data/services.json`
- Detaljsidor per tjänst (t.ex. `s3.html`, `ec2.html`, ...)
- `css/` — styling
- `js/` — fetch-rendering och formulärvalidering
- `data/services.json` — tjänstedata
- `assets/` — ikoner
- `wireframe/` — ursprunglig wireframe
