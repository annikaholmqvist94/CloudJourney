Amazon CloudFront

Kategori: Nätverk/CDN

Amazon CloudFront är ett globalt innehållsleveransnätverk (CDN) som cachelagrar innehåll — bilder, video, HTML, API-svar — nära besökaren, i över hundra platser världen över, för att minska laddtider och avlasta ursprungsservern.

CloudFront kombineras ofta med S3 (för statiska filer) eller ett eget ursprung, och kan även fungera som ett skydd mot vissa typer av attacker genom integration med AWS Shield och WAF.

Bra att veta

  • Cachar innehåll geografiskt nära besökaren via edge-platser.
  • Stöder HTTPS och anpassade domännamn/certifikat.
  • Kan cacha både statiskt och visst dynamiskt innehåll.
