Amazon RDS

Kategori: Databas

Amazon Relational Database Service (RDS) hanterar en relationell databas åt dig — t.ex. PostgreSQL, MySQL eller SQL Server — och sköter saker som patchning, backuper och failover automatiskt istället för att du själv administrerar databasservern.

RDS stöder Multi-AZ-driftsättning för hög tillgänglighet (en stående kopia i en annan datacenterzon som tar över vid fel) och read-replicas för att skala läsbelastning separat från skrivbelastning.

Bra att veta

  • Automatiska backuper med point-in-time-återställning.
  • Flera databasmotorer att välja mellan i samma tjänst.
  • Skalning av lagring och beräkningskraft utan att byta motor.
